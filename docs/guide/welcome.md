# Add dm to your browser

Add dm to your browser is the first window a new dm shows. It helps you
add dm's extension to your browser, so downloads from the browser come to
dm, and lets you confirm where downloads go. It opens once, the first time
dm starts, and only while no browser has ever talked to dm. It does not
open when dm starts hidden in the tray.

It says "Add the extension so downloads from your browser come to dm."

## Fields and buttons

- A button for each browser found on this computer, **Add to …** with the
  browser's name. Each opens the page where that browser's dm extension is
  added. If no browser is found, the window says "No browser found. Here
  is the page for each:" with **Microsoft Edge**, **Firefox** and **Chrome
  and others**.
- **Download folder:** where downloads go. It starts with the download
  folder dm uses now.
- **Browse…:** chooses the folder in the system's folder panel.
- **Start dm with the computer, in the tray:** "So browser downloads always
  reach dm. Change this later in Options › General."
- **Later** and **Done:** both close the window and keep the **Download
  folder** and **Start dm with the computer, in the tray** as they stand.

**Escape**, Ctrl+W (⌘W on macOS) and the close button do the same as
**Done**.

You can change both choices later: the folder in **Options › Folders ›
Download folder**, and starting with the computer in **Options › General › Start
dm when I sign in**.
