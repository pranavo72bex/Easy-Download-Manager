# Download complete

Download complete tells you a download has finished and lets you open it.
It opens by itself when downloads finish, while **Options › General › Show
a message when a download finishes** is on. A download whose own
[progress window](download-window.md) is open finishes in that window
instead.

One window holds everything that finished, newest first. Downloads that
finish while it is open join it. With more than one it says "… downloads
finished."

## For each file

- Its name and size, and under them where it was saved.
- **Open:** opens the file.
- **Open folder:** opens its folder with the file chosen.

To open it with another program, use **Open with…** on its row's menu in
the main window.

A file you act on leaves the window, and the window closes with the last
one.

## Buttons

- **Don’t show this window again:** ticked, closing the window turns off
  **Show a message when a download finishes**, and the status bar says
  "This window won’t open again. Turn it on in Options › General."
- **Close:** closes the window.

## Good to know

- **Return**, **Escape**, Ctrl+W (⌘W on macOS) and the close button all
  close it, keeping what **Don’t show this window again** says.
- It does not open over **Exit dm?** while that is asked; it opens once you
  answer.
