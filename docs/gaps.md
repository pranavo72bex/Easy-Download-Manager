# Gaps

Every known shortfall between dm and a production-ready download manager,
ranked. This is the work list: take the top open item, close it with
evidence (a test or a check that ran), and record the date in its entry.
When a gap closes, move it to "Closed" with what proved it.

Status words, as in `docs/parity.md`:

| Status       | Meaning                                                      |
|--------------|--------------------------------------------------------------|
| OPEN         | Nothing done, or done but never run                          |
| PARTIAL      | Works and is tested, but not everywhere it must              |
| BLOCKED      | Needs something this project cannot get for free, or a person |

## Is dm production ready?

Not yet, as of 2026-10-20. Every menu item, toolbar button and row-menu
item is clicked by its name in `window.rs` and checked for what it does. The
engine, the window, the queue and the extension are tested end to end on
macOS arm64 in Chrome and Firefox and in Linux containers, and CI has built
every installer and installed and run each on its own system — Windows,
macOS, Linux x86_64 and arm64 (2026-10-20). What stops a release is P0:
nothing has run on a person's Windows desktop, nothing is signed, and no
release has been cut (the owner's call).
